# 2026-03-21 — Rendering/storybook dependency upgrades

## image 0.25.8 → 0.25.10

**Why**: eliminates zune-jpeg duplication. `image 0.25.9` pulled `tiff 0.10.3 → zune-jpeg 0.4` alongside its own direct
`zune-jpeg 0.5`, doubling the codec in the binary. Version 0.25.10 bumps tiff to 0.11.2 which unifies on
`zune-jpeg ^0.5`.

- MSRV raised to 1.88.0 (we're on 1.94.0).
- XMP/IPTC metadata extraction for PNG, JPEG, GIF, WebP, TIFF.
- 16-bit CMYK TIFF support.
- Configurable DEFLATE compression level for PNG.

## eframe/egui 0.31 → 0.33

**Why**: two major releases behind; 0.33 brings `egui::Scene` (pannable/zoomable canvas), `Atom`/`AtomLayout`
primitives, `Plugin` trait, pixel-perfect SVG rendering, tessellator improvements (fewer vertices, less overdraw), and
text sharpness/kerning improvements. All useful for the storybook preview viewport.

**Breaking changes**:

- `Rounding` → `CornerRadius`
- `Painter::rect` needs explicit `StrokeKind`
- `CornerRadius`/`Margin`/`Shadow` downsized to u8/i8
- `ColorImage` gained `source_size: Vec2` field — use `ColorImage::new()` instead of struct init
- Menu API rewritten to `Popup`-based system (menus close on click by default)

## cosmic-text 0.17 → 0.18

**Why**: adds text ellipsization (start/middle/end) which we'll need for SDK text components that must fit constrained
display areas. No breaking changes.

## resvg 0.45.1 → 0.47

**Why**: variable font support (`font-variation-settings`), glyph outline caching (perf), and multiple crash fixes (clip
paths, bounding box calculation, glyph splitting). Used by the storybook icon rendering pipeline.

**Breaking changes**:

- Edition 2024, MSRV 1.87
- tiny-skia 0.11 → 0.12

Other additions: radial gradient focal radius (`fr`), nested embedded image loading.

## Not upgraded (ecosystem-blocked)

- **glow 0.16**: 0.17.0 published 2026-03-07 but femtovg, eframe, smithay all still pin `^0.16`.
- **femtovg 0.20.4**: already at latest.
- **taffy 0.9**, **glam 0.32**, **wasmi 1.0**, **winit 0.30**, **glutin 0.32**: semver specs already resolve to latest
  patch versions via Cargo.lock.

## Clippy fixes (Rust 1.94 `collapsible_if`)

Rust 1.94's clippy now flags `if let` + inner `if` as collapsible using let-chains (`if let ... && ...`). Fixed in:

- `bmc-wasm-runtime/sdk-macros/src/json.rs`
- `bmc-storybook/api/src/knobs.rs`
- `bmc-storybook/src/app.rs`
- `bmc-storybook/src/hot_reload.rs`
