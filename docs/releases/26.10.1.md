# 26.10.1 technical release notes

Implementation notes behind the [26.10.1 changelog](../../CHANGELOG.md), by component. 26.10.1 is a bugfix release of
the 26.10 packages; the [26.10 notes](26.10.md) still describe the protocol and compatibility state. Bullets that apply
to one device are tagged `[Deck]` or `[BMM101]`; the rest apply to both.

## Networking

- `bmc-net-drv`: the nl80211 driver decodes the SSID that `iw dev <dev> link` prints before comparing it with the
  requested one. `iw` escapes every non-ASCII byte as `\xHH`, so a UTF-8 SSID such as `Domů` never matched, the join was
  reported as failed and the station was rolled back to the previous network although it had associated. The decoder is
  the supplicant's `printf_encode` one the join watcher already used, now shared through `bmc-net-drv`'s utils `[Deck]`.
- `bmc`: the gRPC web API converts a saved network's encryption type through the same mapping the scan path uses instead
  of casting the domain discriminant to the proto value. `NONE` is 0 in the domain enum but `UNSPECIFIED` is 0 on the
  wire, so every saved network read one step weaker (psk2 as `WPA1_2`, psk-mixed as `WPA`, psk as `WEP_SHARED`), and a
  rejoin from the Network tab, which sends the reported type back with the password, asked a WPA2-only access point for
  `WPA` and never associated.
- `bmc`: the `WifiStatus` network field stays unset when the status carries no configuration instead of a default
  network, which the Network tab drew as an open network with an empty SSID.
- `bmc`: a saved network's signal is bucketed into the `SignalStrength` enum as the scan path does, instead of putting
  the dBm level itself into the field; a saved network without a link reports `UNSPECIFIED`. The Network tab's icon
  knows the four enum values only, so the connected network's row showed no bars.
- `frontend`: the Wi-Fi signal icon looks its bar class up by the mapped icon state, so a weak or moderate link no
  longer draws full bars, and the proto values are mapped in an exhaustive switch.
